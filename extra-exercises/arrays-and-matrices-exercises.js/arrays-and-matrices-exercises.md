# 🏋️ Extra Practice Exercises — Arrays and Matrices

This section contains 10 practical drills developed in **JavaScript** (`arrays-and-matrices-exercises.js`) to reinforce one-dimensional vectors, multi-dimensional matrices (2D grids), index navigation, and data organization within a gaming context.

---

## 📋 Exercise Breakdown (`exe011` to `exe020`)

* **Ex 011 (`exe011`): Shop Weapon Inventory (Basic Array)**
  * **Objective:** Create a one-dimensional array containing available weapons in an RPG shop.
  * **Description:** Declares an array of string items and accesses the first element using zero-based indexing alongside the array length property.

* **Ex 012 (`exe012`): Character Skill Bar Slots**
  * **Objective:** Store a warrior's combat attack commands inside an array.
  * **Description:** Maps out skill shortcuts in an array structure, demonstrating how to retrieve specific tactical abilities by their numeric index.

* **Ex 013 (`exe013`): Pokémon Party Team (2D Matrix)**
  * **Objective:** Create a multi-dimensional array storing Pokémon names and their respective elements.
  * **Description:** Implements a 2D matrix where each row represents a team slot containing heterogeneous string attributes (name and type).

* **Ex 014 (`exe014`): Inventory Grid 3x3 (Matrix Traversal)**
  * **Objective:** Simulate a two-dimensional backpack storage grid.
  * **Description:** Models a 3x3 item bag using a matrix structure, accessing specific grid coordinates (`matrix[row][column]`) to find stored items.

* **Ex 015 (`exe015`): Leaderboard Scores (Numeric Array)**
  * **Objective:** Store top player scores in a sequential numeric vector.
  * **Description:** Uses an integer array to manage server high scores, retrieving specific rank placements by index.

* **Ex 016 (`exe016`): Guild Members Table (Heterogeneous Matrix)**
  * **Objective:** Store guild member names, classes, and levels in a structured table.
  * **Description:** Implements a complex 2D matrix combining strings and numbers to represent detailed character profiles within a guild.

* **Ex 017 (`exe017`): World Map Sectors (Geographic 2x2 Matrix)**
  * **Objective:** Represent regional zones of an exploration map.
  * **Description:** Models an open-world grid using a two-dimensional array to track and navigate through different map sectors.

* **Ex 018 (`exe018`): Combat Log History (String Array)**
  * **Objective:** Record a chronological history of real-time battle chat events.
  * **Description:** Uses a dynamic string array to log combat text actions, retrieving the latest entry using length calculations.

* **Ex 019 (`exe019`): Strategy Board Grid (Tactical Positioning)**
  * **Objective:** Simulate static unit and trap positioning on a tactical board.
  * **Description:** Establishes a 2D matrix grid to manage the exact combat coordinates and entity statuses in a tactical match.

* **Ex 020 (`exe020`): Achievements Unlocked (Array of Booleans)**
  * **Objective:** Track the completion status of in-game trophies and achievements.
  * **Description:** Uses a boolean array to monitor whether specific game milestones have been successfully unlocked or remain locked.
