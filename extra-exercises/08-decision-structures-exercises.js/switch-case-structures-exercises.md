# 🏋️ Extra Practice Exercises — Decision Structures (`switch-case`)

This section contains 10 practical drills developed in **JavaScript** (`exe071` to `exe080`) to reinforce multi-branch selection, `case` matching, `break` flow control, and `default` fallback handling within a gaming context.

---

## 📋 Exercise Breakdown (`exe071` to `exe080`)

* **Ex 071 (`exe071_guild_rank_perks.js`): Guild Rank Daily Perks**
  * **Objective:** Display daily login rewards based on guild rank (`Bronze`, `Silver`, `Gold`, `Platinum`).
  * **Description:** Uses a `switch` statement matching `guildRank` strings to output daily gold rewards and includes a `default` fallback.

* **Ex 072 (`exe072_weapon_enchantment.js`): Weapon Elemental Enchantment**
  * **Objective:** Apply special effect values and bonus stats based on the chosen enchantment stone.
  * **Description:** Uses `switch-case` to configure elemental values (`Fire`, `Ice`, `Lightning`, `Shadow`) and compute total enchantment damage.

* **Ex 073 (`exe073_dungeon_difficulty_select.js`): Dungeon Difficulty Selector**
  * **Objective:** Configure monster level scaling and drop rates based on difficulty selection.
  * **Description:** Uses `switch` on difficulty codes to assign drop rate multipliers and monster levels.

* **Ex 074 (`exe074_mount_speed_bonus.js`): Mount Speed Tier Switch**
  * **Objective:** Determine movement speed bonuses based on the currently summoned mount type.
  * **Description:** Evaluates mount strings (`Horse`, `Wolf`, `Dragon`) using `switch-case` and adds the bonus to base speed.

* **Ex 075 (`exe075_crafting_station_tier.js`): Crafting Station Upgrade Level**
  * **Objective:** Unlock available recipes based on the blacksmith station level.
  * **Description:** Uses `switch` with numeric tiers (`1` through `5`) to display unlocked smithing recipes.

* **Ex 076 (`exe076_arena_game_mode.js`): PvP Arena Game Mode Configuration**
  * **Objective:** Set team player counts based on the selected arena game mode.
  * **Description:** Evaluates game modes (`Deathmatch`, `CaptureTheFlag`, `TeamBattle`) with `switch` to define squad size.

* **Ex 077 (`exe077_potion_brew_effect.js`): Alchemist Potion Brew Results**
  * **Objective:** Determine potion effects based on the primary herb mixed into the cauldron.
  * **Description:** Uses `switch-case` to map herb names (`Moonleaf`, `Sunroot`, `Nightshade`) to specific status buffs.

* **Ex 078 (`exe078_quest_status_tracker.js`): Quest Journal Status Display**
  * **Objective:** Format quest log status based on the quest state code.
  * **Description:** Evaluates status numbers (`0`: Not Started, `1`: In Progress, `2`: Completed) with `switch`.

* **Ex 079 (`exe079_region_weather_generator.js`): Region Weather Switch**
  * **Objective:** Set environmental weather and lighting effects based on the active map region.
  * **Description:** Uses `switch` to assign weather profiles to regions (`Forest`, `Desert`, `Tundra`).

* **Ex 080 (`exe080_class_ability_shortcut.js`): Quick Slot Skill Description**
  * **Objective:** Display skill names and mana costs mapped to hotkey numbers (`1` to `4`).
  * **Description:** Uses `switch-case` to output specific combat ability details and mana costs.
