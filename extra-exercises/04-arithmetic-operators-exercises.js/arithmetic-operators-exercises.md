# 🏋️ Extra Practice Exercises — Arithmetic Operators

This section contains 10 practical drills developed in **JavaScript** (`exe031` to `exe040`) to reinforce arithmetic calculations, string concatenation, increment/decrement, and compound assignment operators within a gaming context.

---

## 📋 Exercise Breakdown (`exe031` to `exe040`)

* **Ex 031 (`exe031_mana_potion_addition.js`): Mana Restoration Addition**
  * **Objective:** Calculate total character mana after drinking a mana potion.
  * **Description:** Adds base mana and potion restoration values using the addition operator (`+`).

* **Ex 032 (`exe032_boss_health_subtraction.js`): Boss Critical Hit Subtraction**
  * **Objective:** Compute remaining boss HP after a critical strike.
  * **Description:** Subtracts critical damage from boss health using the subtraction operator (`-`).

* **Ex 033 (`exe033_spell_damage_multiplication.js`): Magic Spell Damage Multiplication**
  * **Objective:** Calculate final spell output damage using an intelligence scaling factor.
  * **Description:** Multiplies base spell damage by a scaling factor using the multiplication operator (`*`).

* **Ex 034 (`exe034_guild_gold_division.js`): Guild Treasury Gold Division**
  * **Objective:** Distribute guild treasury rewards equally among active members.
  * **Description:** Divides total gold by party member count using the division operator (`/`).

* **Ex 035 (`exe035_inventory_slots_modulus.js`): Inventory Slot Remainder (Modulus)**
  * **Objective:** Calculate unassigned slots in an incomplete inventory row.
  * **Description:** Uses the modulus operator (`%`) to find the remainder of total slots divided by row size.

* **Ex 036 (`exe036_quest_tracker_increment.js`): Quest Tracker Increment (`++`)**
  * **Objective:** Count completed quests sequentially using increment operators.
  * **Description:** Initializes a quest counter at zero and applies the increment operator (`++`) twice.

* **Ex 037 (`exe037_monster_wave_decrement.js`): Monster Wave Decrement (`--`)**
  * **Objective:** Track remaining monsters in a wave after defeats.
  * **Description:** Starts with 5 monsters and applies the decrement operator (`--`) twice.

* **Ex 038 (`exe038_wallet_addition_assignment.js`): Wallet Reward Addition Assignment (`+=`)**
  * **Objective:** Update player currency after receiving a reward.
  * **Description:** Uses compound addition assignment (`+=`) to add bonus gold to the player's wallet.

* **Ex 039 (`exe039_armor_durability_subtraction_assignment.js`): Armor Durability Subtraction Assignment (`-=`)**
  * **Objective:** Reduce equipment durability following heavy impact.
  * **Description:** Uses compound subtraction assignment (`-=`) to decrease armor durability points.

* **Ex 040 (`exe040_agility_multiplication_assignment.js`): Agility Booster Multiplication Assignment (`*=`)**
  * **Objective:** Double a character's agility stat using a multiplier item.
  * **Description:** Uses compound multiplication assignment (`*=`) to double the base agility value.
