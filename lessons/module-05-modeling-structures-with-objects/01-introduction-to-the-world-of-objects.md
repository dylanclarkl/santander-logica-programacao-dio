# 📝 Class 01: Introduction to the World of Objects

## 📌 Main Concepts
An object in JavaScript is a structured container that groups related information (properties) and behaviors (methods) into a single entity using `key: value` pairs. Instead of declaring scattered variables for a single entity's attributes, objects keep all relevant details organized together.

---

## 🛠️ Core Fundamentals

* **Object Literal (`{ key: value }`)**: Defines an object directly using curly braces with comma-separated property names and values.
* **Reading Properties (`object.property`)**: Accesses stored values inside an object using dot notation (e.g., `guest.name` or `character.level`).
* **Dynamic Property Assignment (`object.newProperty = value`)**: Adds new properties or updates existing ones on an object after it has already been created.
* **Object Methods**: Functions defined inside an object that interact with its own properties through `this`.
