# 🏆 Challenge: Pokémon Team Registration

## 🎯 Objective
Create a program using **JavaScript** arrays/matrices to store detailed attributes of a Pokémon team captured from game data, and output a confirmation message for each successfully registered creature.

## 📋 Rules & Requirements
* Store data structures containing Pokémon names, levels, genders, and HP points.
* Display a formatted success message matching the required output pattern: `"[POKEMON_NAME] Cadastrado com sucesso"`.
* Follow clean code standards and English documentation.
