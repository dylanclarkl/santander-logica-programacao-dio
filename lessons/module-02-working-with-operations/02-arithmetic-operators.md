# 📝 Class 02: Arithmetic, Assignment, Increment, and Decrement Operators

## 📌 Main Concepts
* **Arithmetic Operators:**
    Used to perform mathematical calculations. 
    They include addition (`+`), 
    subtraction (`-`), 
    multiplication (`*`), 
    division (`/`), 
    and modulus / division remainder (`%`).
* **String Concatenation:** 
    In JavaScript, the plus sign (`+`) is overloaded: when used with strings or mixed with text, it concatenates values rather than performing mathematical addition.
* **Increment and Decrement (`++` / `--`):** 
    Special shorthand operators used to increase or decrease a variable's numeric value by exactly 1.
* **Assignment Operators (`+=`, `-=`, `*=`, etc.):** 
    Shortcuts that perform an arithmetic operation on a variable and assign the resulting value back to it in a single step.
