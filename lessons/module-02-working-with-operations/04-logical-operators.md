# 📝 Class 04: Logical Operators

## 📌 Main Concepts
Logical operators are used to combine multiple conditions or invert boolean states. They allow developers to create complex decision-making structures in games—such as checking if a character meets multiple prerequisites to enter a special zone, unlock an achievement, or perform an action based on weather and items.

---

## 🛠️ Summary of Logical Operators

* **Logical AND (`&&`)**: 
    Evaluates to `true` **only if all** connected conditions are true. If any condition is false, the whole expression is false.
* **Logical OR (`||`)**: 
    Evaluates to `true` if **at least one** of the connected conditions is true. It only returns false if all conditions are false.
* **Logical NOT (`!`)**: 
    Inverts the boolean value of a condition. It turns `true` into `false`, and `false` into `true`.
