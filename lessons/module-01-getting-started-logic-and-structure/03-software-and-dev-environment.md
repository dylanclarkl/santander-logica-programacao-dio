# 📝 Class 03: Software Structure and Development Environment

## 📌 Main Concepts
* **Software Features:** Features (or functionalities) are the distinct tasks, roles, or actions that an application can perform. For example, in a camera app, the zoom function is a feature. Features vary depending on the app and its core purpose.
* **Input, Process, and Output:** 
  * **Input:** The data or user actions provided to the system (e.g., clicking buttons, typing personal data, setting pickup and destination locations).
  * **Process:** The internal validation and logic rules executed by the system behind the scenes (e.g., checking for registration irregularities, verifying credit card availability, finding nearby drivers).
  * **Output:** The final response or feedback delivered back to the user (e.g., success messages, estimated arrival times, status updates).
