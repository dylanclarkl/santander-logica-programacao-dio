# 📝 Class 04: Variables and Data Types

## 📌 Main Concepts
* **What is a Variable:** Think of variables as containers or labeled jars (like Grandma's jars for coffee, sugar, and cookies) used to store data in memory that can be changed or reused later[cite: 11].
* **`let` vs `const`:**
  * **`let`**: Used for variables whose values can be updated or changed during the program execution (e.g., updating a player's level or changing coffee brands)[cite: 10, 11, 12].
  * **`const`**: Used for constants — values that remain fixed and cannot be reassigned once defined (e.g., system notifications or static messages)[cite: 10, 11].

---

## 📊 Data Types in JavaScript
* **String:** Used to store text sequences (e.g., `"Pikachu"`, `"Maria"`)[cite: 12].
* **Number:** Used to store numeric values, both integers and decimals (e.g., level `20`, HP `45`)[cite: 12, 13].
* **Boolean:** Logical type that stores true or false values (`true` or `false`) (e.g., `selecionavel = false`)[cite: 12, 13].

---

## 💻 Practical Examples Covered
* **The Gamer Context:** Storing player nicknames, notifications, and concatenating strings with variables[cite: 10].
* **The Pokémon Context:** Storing Pokémon attributes like name, gender, level, health points (HP), and selection status[cite: 12].
