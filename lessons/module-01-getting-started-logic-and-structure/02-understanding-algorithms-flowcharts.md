# 📝 Class 02: Understanding Algorithms and Flowcharts

## 📌 Main Concepts
* **What is an Algorithm:** A finite sequence of logical steps or instructions designed to solve a specific problem. Just like game mechanics where a hero needs to walk, attack, or jump over an obstacle to clear a phase, programming requires a sequential plan.
* **Flowcharts:** Visual representations of an algorithm using standardized geometric shapes to map out the execution flow, decisions, and processes.

---

## 🔑 Key Symbols & Structure in Flowcharts
Flowcharts use specific shapes to represent different actions:
* **Start / End:** Rounded rectangle / oval (`inicio` / `fim`)
* **Decision:** Diamond shape (`if / else` conditions like "Is the oven lit?" or "Are there enough blocks?")
* **Process:** Rectangle representing standard operations (e.g., "add wood", "build shelter")[cite: 3, 4, 5]
* **Input / Output (Data/Document):** Parallelogram for user input or output messages (e.g., "enter shelter name", "Shelter finished")

---

## 💡 Practical Examples Covered
1. **The Hero's Path:** Moving right, attacking, jumping, and moving right again to bypass a pit and defeat an enemy[cite: 1, 2].
2. **The Bakery Process:** Opening the oven, checking if it is lit (if yes: add wood; if no: ignite fire), and baking the bread[cite: 3].
3. **The Shelter Builder (Loops):** Entering a shelter name, checking for blocks, gathering more if insufficient (using a loop), building the shelter, and finalizing.
