# 📝 Class 05: Arrays and Matrices

## 📌 Main Concepts
* **Variables vs. Arrays vs. Matrices (The Storage Analogy):**
  * **Variable (Single Box):** Stores only one value at a time.
  * **Array / Vector (Single-Row Locker):** A one-dimensional list capable of storing multiple values sequentially under a single variable name.
  * **Matrix (Two-Dimensional Locker):** A multidimensional array (an array of arrays) organized in rows and columns, ideal for tabular data.

---

## 🔑 Key Takeaways
1. **Zero-Based Indexing:** In JavaScript, array and matrix positions always start at index `0` (the first element is `[0]`, the second is `[1]`, and so on).
2. **Accessing Matrix Data:** To access a specific item inside a matrix, use two bracket pairs: `matrix[row][column]`.
3. **Mixed Data Types:** JavaScript arrays and matrices can store different data types together (e.g., strings for names/gender and numbers for levels).
