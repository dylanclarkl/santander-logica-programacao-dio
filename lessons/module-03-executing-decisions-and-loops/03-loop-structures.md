# 📝 Class 03: Loop Structures (for, while, do-while)

## 📌 Main Concepts
Loop structures are used to repeat a block of code multiple times based on specific conditions. They automate repetitive tasks, array traversals, and game loops without requiring redundant code duplication.

---

## 🛠️ Summary of Loop Structures

* **`for` Loop**: Ideal when the number of iterations is known in advance. It manages initialization, condition checking, and incrementing within a single statement.
* **`while` Loop**: Used when the exact number of iterations is unknown. It evaluates a boolean condition before executing the code block.
* **`do-while` Loop**: Similar to the `while` loop, but guarantees that the code block executes **at least once** before evaluating the condition at the end.
