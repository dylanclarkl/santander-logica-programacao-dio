# 📝 Class 01: Conditional Structures (if, else if, else)

## 📌 Main Concepts
Conditional structures allow your program to make decisions based on different scenarios and boolean evaluations. Just like an adventurer facing a fork in the road, code execution branches out depending on specific conditions.

---

## 🛠️ Summary of Conditional Statements

* **`if` Statement**: Evaluates an initial condition. If the expression evaluates to `true`, the enclosed code block runs.
* **`else if` Statement**: Provides an alternative condition to test if the preceding `if` (or previous `else if`) condition evaluated to `false`.
* **`else` Statement**: Acts as a fallback catch-all block. It executes only if all preceding conditions in the chain evaluate to `false`.
