# 📝 Class 02: Decision Structures (Switch Case)

## 📌 Main Concepts
The `switch` statement is a control flow structure used to evaluate an expression and execute different code blocks based on matching case values. It serves as a cleaner, more readable alternative to long chains of `if...else if...else` statements when checking a single variable against multiple discrete options.

---

## 🛠️ Summary of Switch Case Keywords

* **`switch`**: Declares the evaluation expression, telling the computer to start checking options based on a given value.
* **`case`**: Defines specific target options or matches to compare against the expression.
* **`break`**: Terminates the current case execution block, preventing code execution from falling through to subsequent cases.
* **`default`**: Acts as a fallback option that executes if none of the preceding `case` statements match the evaluated expression.
