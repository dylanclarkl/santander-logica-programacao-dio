# 📝 Class 01: What Functions Are and How to Create Them

## 📌 Main Concepts
A function is a reusable block of code designed to perform a specific action whenever it is invoked. Instead of repeating the same steps across a script, functions group actions under a clear name, allow one function to call another, and can accept input values when invoked.

---

## 🛠️ Core Fundamentals

* **Function Declaration (`function name() {}`)**: Defines a named block of instructions that runs when called. In JavaScript, function declarations are hoisted, meaning you can invoke them even above the line where they are declared.
* **Function Invocation (`name()`)**: Executes the code inside the function body at the exact point where it is called.
* **Function Chaining (Calling Functions Inside Functions)**: A function can trigger helper functions inside its body to break a larger action—like preparing equipment or forging gear—into clear sub-steps.
* **Passing Values on Call**: Functions can accept input values (such as a hero name or item target) when called to customize their output.
