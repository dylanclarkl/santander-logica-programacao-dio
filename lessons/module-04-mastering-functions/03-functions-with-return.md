# 📝 Class 03: Functions with Return

## 📌 Main Concepts
The `return` statement sends a value back from a function to the caller. Instead of only printing output inside the function, returning values lets you store results in variables, combine them with other logic, or pass them into conditions.

---

## 🛠️ Core Fundamentals

* **Returning Computed Values (`return`)**: Hands back the result of an expression or transformation (such as a sum or parsed text segment) to where the function was called.
* **Storing and Reusing Output**: Assigning a function call to a variable (`let result = fn(...)`) lets you format messages, check thresholds, or update state later.
* **String Splitting with Delimiters**: Combining `.split(delimiter)[0]` with `return` extracts the leading portion of a formatted name or tag cleanly.
