# 📝 Class 02: Functions with Parameters

## 📌 Main Concepts
Parameters are named placeholders declared inside a function definition that receive concrete values—called arguments—when the function is invoked. They let one function run different inputs and calculations without duplicating code.

---

## 🛠️ Core Fundamentals

* **Single Parameter**: A function can accept one input value (such as a hero name or target) and adapt its message or action on each call.
* **Multiple Parameters**: Comma-separated parameters (`param1, param2`) pass several values into the function body in order.
* **Default Parameter Values**: Assigning a fallback value (`param = defaultValue`) prevents `undefined` behavior when an optional argument is omitted.
